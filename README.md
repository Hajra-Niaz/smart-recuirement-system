# 🤖 Smart Recruitment System (AI-Powered ATS)

An intelligent Applicant Tracking System (ATS) built with Flask and OpenAI. This system analyzes resumes and interviews to provide comprehensive candidate evaluations, helping recruiters make data-driven hiring decisions.

## ✨ Features

- 📄 **Resume Analysis**: Upload PDF/DOCX resumes against a specific job title. The AI extracts skills, evaluates experience, and calculates a match percentage.
- 🎤 **Interview Analysis**: Analyze text-based interview Q&As to evaluate communication skills, technical knowledge, and cultural fit.
- 📊 **Comprehensive Scoring**: Get detailed scores for skills, experience, communication, and more.
- 🎯 **Final Recommendations**: Receive AI-generated hiring recommendations and actionable feedback based on combined analysis.

## 🛠️ Tech Stack

- **Backend**: Python, Flask
- **AI Engine**: OpenAI API (GPT-3.5-turbo)
- **Document Parsing**: PyPDF2, python-docx
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Deployment**: Gunicorn, Render
